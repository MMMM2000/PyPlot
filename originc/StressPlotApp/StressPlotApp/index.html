Stress Dependence Plotter

Select one or more measurement text files (*.txt or *.csv) and choose which variables to analyse. This app will load all files, compute raw and mean curves for each variable across all groups and directions, and generate Origin graphs by calling a Python back‑end and Origin C. Baseline values are computed from the first or minimum point in each dataset. Use the options below to specify whether plots should be shown on screen and/or saved to disk. An optional graph template (.otp) and export path for a PNG file may also be provided.
