TMA and Current Annealing now capture Git/source provenance exactly once per run or prepared output on bounded daemon tasks, preventing source-control queries from delaying control or GUI threads. The Git branch, commit, and worktree state come from one coherent status query; late completion atomically patches only `source_control` in the matching metadata file. Metadata retains the existing source-control keys and adds explicit pending/completed/unavailable timestamps and states, including `dirty_state` values that distinguish unknown capture results from a clean worktree.
