# Work tracking

Current priorities and integration decisions belong to the master chat's active
ledger. Use [docs/work-register.md](docs/work-register.md) for worker handoffs and
[AGENTS.md](AGENTS.md) for repository rules.

The previous planned/done list is preserved in
[the historical task ledger](docs/history/task-ledger-pre-2026-10-22.md). Its items
and verification claims need reconciliation against the current branch and PRs;
archiving this list does not mark pending scientific/Origin acceptance complete.
