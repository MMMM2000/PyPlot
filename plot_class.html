dict ) 
set the z-levels from the modified dictionary returned from the getter

    graph = op.new_graph(template='contour')
    gl = graph[0];
    plot = gl.add_mplot(msheet, z=0, type='contour')
    gl.rescale()

    plot.zlevels = z
